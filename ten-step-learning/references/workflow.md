# Ten-step workflow

## File set

Use stable numbered names, adapted to the topic:

1. `00-学习索引与进度.md`
2. `01-五种视角与证据.md`
3. `02-矛盾清单.md`
4. `03-行业简报.md`
5. `04-可信度审计.md`
6. `05-学习资源与七天路线.md`
7. `06-五级学习阶梯.md`
8. `07-二十小时十节课.md` plus a live lesson record or per-lesson files
9. `08-逐题考核记录.md`
10. `09-费曼学习记录.md`
11. `10-五分钟速查表.md`

Use the user’s terminology for “行业” when the topic is not an industry. Keep an index that states what is complete, in progress, awaiting input, or unverified.

## Steps 1–6 — Research and plan

1. Simulate practitioner, scholar, skeptic, economist, and historian lenses. Give position, strongest evidence, distinctive information, and limitation. Label roles as simulations.
2. List viewpoint conflicts, evidence strength, minimum consensus, blind spots, and factual discrepancies. Explain which evidence answers which question.
3. Write a roughly 60-second overview, five findings ordered by confidence, and a next-day action plan. Mark untimed speaking length as estimated.
4. Score each finding 1–10 as a transparent judgment, not statistical probability. Mark 6 or below low confidence and state verification needs and bias.
5. Choose five strong resources with advantage, estimated time, core idea, and pitfalls. Build a seven-day route and verify access.
6. Build five learning levels, each with an observable passing standard, common trap, and self-check question. Reading alone is not mastery.

## Step 7 — Twenty-hour, ten-lesson course

Design ten lessons totaling 20 estimated hours. Each lesson needs core content, source material, practice, review questions, and output. Include a final applied project and rubric.

Then teach the course in sequence. Use explanation and teacher-worked examples before examination when the user requests “learn first, test later”. Save each delivered lesson. State that lesson delivery is not proof of two hours of study or mastery.

## Step 8 — Ten-question examination

Create ten questions from basic concepts through comparison, evidence appraisal, and transfer. Avoid reusing exact examples that already revealed answers. Ask one question per turn and retain the learner’s answer verbatim. Apply `assessment.md`.

## Step 9 — Feynman cycle

Target actual weak points. Explain one concept using ordinary life, request a concise child-friendly retelling, identify the precise misunderstanding, reteach with a different example, and require transfer to a new context. Complete only after a genuine learner response passes transfer.

## Step 10 — Cheat sheet and audit

Create a five-minute review sheet built around actual errors. Include core distinctions, a rapid decision checklist, evidence boundaries, frequent traps, and a 60-second self-test. Audit every file, internal link, score, pending item, source limitation, and claimed status.

If asked to package this workflow as a Skill and it is not installed, use skill-creator, stage a reviewable package, validate it, then install it to the discoverable skills directory. Do not claim installation until the installed copy is validated.
