# 十步学习法 Skill（ten-step-learning）

把一个陌生主题从多视角研究、证据审查和课程学习，一直推进到逐题考试、费曼复述与五分钟复习。

它适合需要系统建立知识框架、实际学习并检验理解的主题。若只想查询一个事实或获得简短解释，不必启动完整流程。

## 能做什么

1. 模拟实践者、学者、怀疑者、经济学家和历史学家五种分析视角。
2. 整理观点冲突、证据强弱、最低共识和研究盲区。
3. 生成60秒概述、五个关键发现和次日行动建议。
4. 给发现标注可信度、低把握信息、验证需求和资料偏见。
5. 筛选五个学习资源，并编排七天学习路线。
6. 建立五级学习阶梯，提供达标标准、高频错误和自测题。
7. 设计20小时、10节课的课程，并按顺序实际讲授。
8. 逐题进行10道考试题，保留首次得分，薄弱点另行补练。
9. 使用费曼学习法重讲，并通过新情境复述检验迁移能力。
10. 根据真实错题生成五分钟速查表，完成文件和进度审计。

## 安装

将整个目录复制到 Codex 的个人 Skill 目录：

```bash
mkdir -p ~/.codex/skills/ten-step-learning
cp -R ten-step-learning/. ~/.codex/skills/ten-step-learning/
```

重新打开 Codex 后，可以显式调用：

```text
$ten-step-learning
```

也可以直接说：

```text
按十步法带我学行为经济学
```

## 使用示例

```text
按十步法带我学统计学中的因果推断
```

```text
按十步法带我学产品经理需要掌握的用户研究
```

```text
继续上次的十步学习
```

Skill 会为每个主题建立进度索引，并在需要用户回答的考试或复述环节等待真实输入。回复“继续”会从记录的下一步恢复，不会重新开始。

## 十步流程

| 步骤 | 产物 | 关键要求 |
|---|---|---|
| 1 | 五种视角与证据 | 五种角色是分析视角，不冒充真实专家 |
| 2 | 矛盾清单 | 区分观点冲突、事实冲突和证据适用范围 |
| 3 | 学习简报 | 60秒概述、五项发现、次日行动 |
| 4 | 可信度审计 | 分数是透明判断，不冒充统计概率 |
| 5 | 资源与七天路线 | 写明优势、时间、核心点和避坑内容 |
| 6 | 五级学习阶梯 | 每一级都要有可观察的达标标准 |
| 7 | 20小时10节课 | 先设计课程，再按顺序实际讲授 |
| 8 | 10题逐题考试 | 一次一题，首次分与补练分分开保存 |
| 9 | 费曼学习记录 | 用户复述并通过陌生情境迁移才算完成 |
| 10 | 五分钟速查表 | 根据真实错题生成，并审计全部状态 |

“20小时”是课程的建议学习容量。仅生成或展示课程内容，不代表学习者已经投入20小时或掌握全部内容。

## 评分规则

每道题满分10分：

- 核心概念：4分
- 推理或例子：3分
- 边界意识：2分
- 表达清晰：1分

0—6分或存在关键误解时进行同概念补练。首次成绩保持不变，补练结果单独记录。

## 证据边界

- 区分来源事实、学术解释、教学综合和未经验证的主张。
- 思想启发、个人感受、教学练习和临床疗效不是同一种证据。
- 涉及医学、心理健康、法律或财务时，优先核对当前权威来源。
- 哲学框架不能替代诊断、治疗或紧急援助。
- 文件生成、课程讲授、考试成绩和真实长期掌握分别记录。

## Skill 文件

```text
ten-step-learning/
├── SKILL.md
├── README.md
├── agents/
│   └── openai.yaml
└── references/
    ├── assessment.md
    └── workflow.md
```

- `SKILL.md`：触发条件、总流程和交互规则。
- `references/workflow.md`：十步产物与执行要求。
- `references/assessment.md`：考试、补练和费曼通过标准。
- `agents/openai.yaml`：Codex 中显示名称和默认提示词。
