# Ten-Step Learning

Run the complete workflow in order and preserve progress after every step. Read [references/workflow.md](references/workflow.md) before starting a new topic or resuming an unfinished run. Read [references/assessment.md](references/assessment.md) before steps 8–10.

## Start and save

Infer the topic from prompts such as “按十步法带我学XX”. Ask only for missing information that materially changes the work. If a local Obsidian vault is established by the user or workspace instructions, save there; otherwise create a clearly named local output folder. Never overwrite an unrelated note.

Create an index with the topic, date, file links, current step, pending user input, and next action. Save each step in a separate Markdown file. Resume from recorded state instead of restarting or silently skipping unfinished interaction.

## Evidence discipline

Separate source facts, scholarly interpretation, teaching synthesis, and unverified claims. Use current authoritative or primary sources when claims are unstable, high stakes, or evidence dependent. Record access date, source type, and material limitations. Mark simulated practitioner, scholar, skeptic, economist, and historian views as analytical lenses rather than five independent experts.

Do not treat philosophical insight, personal inspiration, teaching exercises, and clinical effectiveness as interchangeable evidence. For health topics, avoid diagnosis and preserve professional-assessment boundaries.

## Required sequence

Complete steps 1–7 in order and save each result. Step 7 has two parts: design the ten-lesson course, then actually teach all ten lessons interactively. A course outline does not count as teaching, and supplied lesson text does not prove the learner spent 20 hours or mastered it.

After teaching, run step 8 one question per turn. Wait for the learner’s real answer, score it, explain the gap, and use a same-concept follow-up when needed. Preserve first-attempt scores; list remediation separately.

After all ten questions, run step 9. Explain weak concepts in language a 12-year-old can understand, obtain the learner’s own retelling, reteach only the unclear part, and use a new-context transfer check. Do not simulate the learner’s answer or mark the step complete early.

Only after step 9 passes, create step 10: a five-minute cheat sheet tailored to the learner’s actual errors, a final progress audit, and any requested reusable artifact. If this skill is already installed, do not recursively create another copy of itself; finish the learning artifacts and record completion.

## Interaction rule

When a step needs a learner response, end with exactly one clear prompt. Do not bundle multiple future questions. A user message such as “继续” advances to the recorded next action; it is not an answer to a pending substantive question unless it actually addresses that question.

## Completion

Report separately: research artifacts completed, lessons delivered, first-attempt exam score, remediation results, Feynman transfer result, remaining uncertainty, and saved paths. Never equate file creation with learning completion.
